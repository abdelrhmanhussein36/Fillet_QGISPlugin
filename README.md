This plugin allows you to fillet (round) corners of polygon features by creating smooth tangent arcs between two adjacent edges. 
Perfect for agricultural fields, land boundaries, and any polygon that needs rounded corners.
\n\nFeatures:\n• Auto-calculates maximum possible radius based on edge lengths\n• Visual preview before applying\n• Works with multipart polygons\n• ArcGIS Pro style workflow\n\nHow to use:\n1. 
Select a polygon layer in the Layers panel\n2.
Enable editing mode (yellow pencil icon)\n3. Launch Fillet Tool from toolbar or Plugins menu\n4.
Click 'Pick Polygon' and click inside your polygon\n5. Click 'Pick Corner' and click on the corner vertex\n6.
Adjust radius (auto-set to 80% of max)\n7. Click 'Apply Fillet'
